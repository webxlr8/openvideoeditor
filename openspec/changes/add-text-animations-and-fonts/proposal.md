# Proposal: add-text-animations-and-fonts

## Why

Text needs entrances and exits and real typefaces to look finished.

## What Changes

- 16 text animation presets plus none, each with duration, delay, easing and an out phase.
- A font library of 16 OFL families with licences, installed system fonts via fontdb, `fontFamily`/`fontWeight`/`fontStyle` honoured with variable weight axes.
